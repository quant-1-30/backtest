## 二、残留硬伤（未修复，按对回测-实盘偏离的影响排序）

### P0：涨跌停无撮合硬约束

`Asset.restricted()`（返回标的当日涨跌幅限制比例，含新股/ST/板块差异化）**当前零调用者，是死代码**。撮合层唯一的触板处理是 `_execute_factor` 启发式：仅当 bar 振幅 < 1e-5 且收盘处于区间极值时拒绝成交。造成三类失真：

1. **涨停价买入被放行**：市价买单在任何有振幅的涨停 bar 照常成交，且成交价可越过涨停价；
2. **跌停价卖出被放行**：回测可以"逃跌停"成功，实盘挂单排队未必成交；
3. **一字板建模不完整**：盘中开板回封（振幅 > 0）的 bar 仍可全量成交，忽略封单排队。

**定性影响**：这是与实盘偏离的最大单一来源。打板/追涨/小市值/ST 策略的回测收益系统性高估；对沪深 300 成分股低频调仓影响有限（触板频率低）。

**修复方向**（估 1-2 天）：filler 注入 prev_close 与 `restricted()` 幅度 → 买单价 clamp 至涨停价、卖单 clamp 至跌停价；触板 bar 的可成交量按 `(bar成交量 - 封单估计) × impact` 折减或直接置零；一字板（open==high==涨停价）买单直接拒绝。

### P1（按序）

1. **交易日历无节假日表**：`tradingcal.holidays` 默认空，仅剔除周末 + 手工 2016 熔断半日。bar 驱动时钟下大部分场景被数据掩盖，但 timer/session 排程、`ts2intdt` 对齐类逻辑在假日边界有隐患。建议内置 `exchange_calendars` 的 XSHG/XSHE 日历。
2. **分红个税（差别化征税）未实现**：持有 >1 年免征、1 月–1 年 10%、<1 月 20%。长线策略收益小幅高估。
3. ~~**日内 VWAP 用全天量归一（未来函数）**~~ **已消除（2026-08-25）**：`AlgoFiller._execute` 的 VWAP/TWAP 调度整体注释禁用（进度分母依赖提交时刻不可知的全天量/剩余 bar 数），委托 `PseudoFiller` 逐 bar 因果撮合（量×impact 参与语义）；b"vwap"/b"twap" 注册保留兼容历史参数。
4. **佣金/最低佣金硬编码**（万 5、5 元起）：实盘万一免五账户成本被高估 ~数倍于真实值，对小资金高频换手策略是可感知偏差。应参数化到 store/broker 配置。
5. **吸并/退市按全额损失处理**（positions/sqn analyzer），换股吸收合并路径未建模。
6. **科创板最小申报 200 股** 以 tick_size 近似，未按 1 元递增的规则申报。

### P2

多 data feed 未按时间戳严格归并对齐；`publish_metric` 多生产者递增非原子（当前单生产者架构无害）；strategy `clk_update` 用 np.max 的时钟漂移；事件 merge 后 analyzer 历史断裂（已降级为 warning 跳过，但统计口径仍受影响）。

## 三、分策略类型适配结论

| 策略类型 | 当前可信度 | 主要偏离源 |
|---|---|---|
| 日线调仓、沪深 300/中证 500 成分、低频 | **高** | 费用模型已准；触板频率低 |
| 日线小市值/高 beta/高换手 | **中** | 涨跌停 P0 |
| 打板/涨停板/ST 策略 | **不可用** | 涨跌停 P0（成交可行性整体失真） |
| 分钟级执行、日内策略 | **中** | VWAP 未来函数已消除；剩节假日表 + 次晨卖单"次开≈前收"近似 |
| 分红/配股事件驱动 | **高**（本次修复后） | 分红税 |
| 多标的组合（日线及以上） | **高**（2026-08-25 闭环后） | 次晨卖单"次开≈前收"近似常态化（见下） |
| 2015 年前长历史回测 | **中** | 费率分界已修；旧过户费按面值规则的精确申报未建 |

**多标的闭环验证（2026-08-25，tests/test_multi_instrument.py + tests/verify_event_cash.py）**：3 标的（300308 深创业/600000 沪主板/000001 深主板）、日/周/月三周期 resample、2012-01→2026-05、按日轮动信号：2509 单/3483 笔成交/3388 交易日——**费率恒等式 3483/3483 命中（max_err 0.000000，含沪深交易所路由与全部费率分界）；现金守恒残差 0.0000（9 笔分红逐笔闭环）；仓位轨迹 1334/1338 行精确、4 行次日自愈**。过程中确认的关键语义（agents.md §5.12）：策略时钟在 timer 派发时停在上一根 bar，D+1 晨 on_risk 卖单盖 D 末根 bar 戳并按戳回填成交——多标的每日轮动下成为常态，是"次开≈前收"执行近似的系统性体现（对高换手策略为已知偏差源，非记账错误）。
